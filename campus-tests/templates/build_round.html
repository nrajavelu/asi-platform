3 manual steps required in the Editor before any real candidate uses this form

These aren't exposed via the Forms API — verified directly against the live API schema, they genuinely don't exist there. Open the Edit URL above and set all three:

  1. Settings > Responses > Collect email addresses → Verified. Matches responses to candidates. A response submitted before this is on can never be matched retroactively — that candidate must submit again.
  2. Settings > Responses > Limit to 1 response. Blocks a second submission per Google account.
  3. Settings > Quizzes > Release grade → Later, after manual review. Hides both the score and correct answers from the candidate right after they submit.

Timer: open the timer page above in a browser and display it on the room's projector/shared screen — click Start when the session begins. Google Forms has no native timer.
